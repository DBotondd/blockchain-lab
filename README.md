# Blockchain Lab – online (Render)

A Python/Streamlit oktatási blokklánc + két valódi Solidity-okosszerződés helyi Ganache EVM-en.

**Telepítés:** [ONLINE_TELEPITES.md](ONLINE_TELEPITES.md).

Az online Docker-változatban a Solidity-forrás **a konténer összeállításakor** kerül fordításra 0.8.20-szal; az alkalmazás futás közben a lefordított ABI-t és bájtkódot tölti be, a Ganache EVM-en a szerződéseket valóban telepíti és futtatja. A Python-blokklánc továbbra is külön helyi modell.

A Render Free: ingyenes, 512 MB RAM és alvó állapot 15 perc tétlenség után. A teljes alkalmazás felhős működése a tényleges telepítési próbán igazolható.
